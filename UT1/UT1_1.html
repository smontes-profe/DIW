Elementos del diseño visual

Punto, línea y forma

El punto es el elemento más básico; varios puntos generan líneas y las líneas delimitan formas. En digital, podemos expresarlos con div, SVG y bordes CSS.

01

Punto

Un foco visual mínimo

HTML 
<div class="punto"></div>
CSS 
.punto {
  width: 40px;
  height: 40px;
  background: coral;
  border-radius: 50%;
}
02

Línea

Dirección y recorrido

HTML 
<div class="linea"></div>
CSS 
.linea {
  width: 180px;
  border-top: 4px solid teal;
}
03

Forma

El contorno organiza el espacio

HTML 
<div class="circulo"></div>
CSS 
.circulo {
  width: 60px;
  height: 60px;
  border: 3px solid goldenrod;
  border-radius: 50%;
}
Otras formas 
.cuadrado { border: 3px solid goldenrod; }
.triangulo {
  border-bottom: 60px solid goldenrod;
  border-left: 35px solid transparent;
  border-right: 35px solid transparent;
}

El mismo lenguaje, otra herramienta

Una forma también puede dibujarse con SVG

SVG permite describir la geometría con elementos como circle y line. Este es un ejemplo mínimo y visible.

SVG 
<svg width="180" height="100">
  <circle cx="50" cy="50" r="20" />
  <line x1="90" y1="50"
        x2="170" y2="50" />
</svg>
