Micro-lección 01

Punto, línea y forma

Las unidades mínimas que construyen una composición. En digital, podemos expresarlas con div, SVG y bordes CSS.

Punto

Un foco visual mínimo

.punto {
  width: 40px;
  height: 40px;
  border-radius: 50%;
}

Línea

Dirección y recorrido

.linea {
  width: 180px;
  border-top: 4px solid teal;
}

Forma

El contorno organiza el espacio

.circulo {
  border: 3px solid goldenrod;
  border-radius: 50%;
}

Micro-lección 02

Plano, volumen y textura

El plano organiza el espacio, el volumen crea sensación de profundidad y la textura aporta riqueza visual.

Plano

Una superficie que organiza

.plano {
  width: 180px;
  height: 100px;
  background: steelblue;
}

Volumen

Profundidad simulada

.cubo {
  box-shadow: 14px 14px 0 #b94738;
  transform: perspective(300px)
    rotateX(8deg) rotateY(-12deg);
}

Textura

Profundidad visual

.textura {
  background-color: #eab84b;
  background-image: radial-gradient(
    #9b7411 1px, transparent 1px);
}

Micro-lección 03

Distribución y espacio negativo

La posición y el tamaño construyen equilibrio. El espacio en blanco también participa: separa, ordena y deja respirar la composición.

Equilibrio simétrico

Estabilidad y orden

.simetrica {
  display: flex;
  justify-content: space-between;
  padding: 0 20%;
}

Equilibrio asimétrico

Tensión y movimiento

.grande { width: 110px; }
.pequena { width: 36px; }
/* El peso visual se compensa */

Espacio negativo

Silencio que organiza

respira 
.marco {
  padding: 42px;
  background: white;
}
/* El espacio mejora la lectura */

Micro-lección 04

Tipografía web e iconografía

La tipografía define la legibilidad y la personalidad de una interfaz. Los iconos y los gráficos SVG comunican ideas de forma rápida y conservan su nitidez.

Serif

Tradición y elegancia

Diseño que cuenta historias 
font-family: Georgia, serif;

Sans-serif

Claridad en pantalla

Diseño que guía 
font-family: 'DM Sans', sans-serif;

Monospace

Precisión para código

const interfaz = true; 
font-family: Consolas, monospace;

Criterios de legibilidad

Leer también es una experiencia.

16px · line-height: 1.5 · 60-75 caracteres
El tamaño, el interlineado y el ancho de columna reducen la carga cognitiva. Un buen emparejamiento tipográfico establece contraste entre encabezado y cuerpo.

Iconografía y SVG

Un icono, una idea instantánea.

Los SVG se definen matemáticamente: escalan sin pixelar y pueden incluir una etiqueta accesible. 

<svg viewBox="0 0 64 64" role="img"
  aria-label="Icono de accesibilidad">
SVG nítido en cualquier pantalla

Idea clave

El vacío también tiene peso visual.

Una distribución equilibrada no busca que todo ocupe el mismo espacio. Busca que cada elemento tenga el espacio que necesita para ser comprendido.
