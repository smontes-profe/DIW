Distribución
y espacio negativo

La posición y el tamaño de cada elemento construyen equilibrio. El espacio en blanco también participa: separa, ordena y deja respirar la composición.

Tensión y movimiento

respira

Idea clave

El vacío también tiene peso visual

Una distribución equilibrada no busca que todo ocupe el mismo espacio. Busca que cada elemento tenga el espacio que necesita para ser comprendido.
