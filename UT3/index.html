Etiqueta <audio> y atributos

Permite integrar sonido en la interfaz de forma nativa. Debe incorporar siempre controles visibles y ofrecer formatos alternativos para garantizar compatibilidad entre navegadores.

Referencia técnica Atributos clave

Atributos principales de <audio>

  • controls Muestra la interfaz nativa del navegador (play/pause, volumen y tiempo). Imprescindible para el usuario.
  • preload Define la estrategia de precarga: none (ahorra datos), metadata (solo duración y peso) o auto.
  • loop Reinicia la reproducción indefinidamente al terminar la pista.
  • muted Inicia la reproducción con el sonido silenciado.
  • autoplay Inicia el audio automáticamente. Evitar en producción: deteriora la accesibilidad y los navegadores modernos lo bloquean salvo que esté silenciado.

Etiqueta <video> y carátula poster

Permite proyectar secuencias de vídeo con control total sobre su dimensionamiento, carátula estática previa y modos de precarga.

Reproductor de vídeo con carátula

El atributo poster muestra una imagen representativa mientras el vídeo no se ha iniciado, evitando recuadros negros o saltos de diseño (CLS).

Código HTML5 
<video controls poster="media/poster.svg" preload="metadata" width="720" height="405" playsinline>
  <source src="media/video-ejemplo.mp4" type="video/mp4">
  <source src="media/video-ejemplo.webm" type="video/webm">

</video>

Bloque 03

Accesibilidad: pistas <track> y WebVTT

La inclusión multimedia debe garantizar el acceso a personas con discapacidad auditiva o dificultades de comprensión lingüística mediante subtítulos normalizados en formato WebVTT.

Subtítulos interactivos Formato .VTT

Vídeo con subtítulos en castellano

Reproduce el clip y comprueba el selector de pistas nativo (icono [CC]). El archivo subtitulos.vtt proporciona los textos sincronizados por intervalos de tiempo.

Código con etiqueta <track> 
<video controls poster="media/poster.svg">
  <source src="media/video-ejemplo.mp4" type="video/mp4">
  <track kind="subtitles"
         src="media/subtitulos.vtt"
         srclang="es"
         label="Español"
         default>
</video>

Bloque 04

Reproductores adaptables con CSS

Un error habitual en interfaces es declarar anchos fijos en píxeles que desbordan las pantallas móviles. Con CSS moderno garantizamos fluidez y preservamos la relación de aspecto panorámica.

✓ Recomendado: Fluido con aspect-ratio
CSS moderno 
.fluid-video {
  width: 100%;
  height: auto;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  border-radius: 8px;
}

Se estira y encoge suavemente adaptándose al contenedor padre sin distorsión geométrica ni recortes indebidos.

Técnica clásica: Contenedor proporcional
CSS compatible navegadores antiguos 
/* Patrón clásico basado en padding-top */
.video-ratio-box {
  position: relative;
  width: 100%;
  padding-top: 56.25%; /* 9 / 16 = 56.25% */
}

.video-ratio-box video {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
}

Utilizado cuando se requiere compatibilidad con motores de render anteriores a la especificación nativa de aspect-ratio.

Bloque 05

Formatos y pautas de usabilidad

El diseño de interfaces exige encontrar el equilibrio exacto entre fidelidad audiovisual, peso de descarga, consumo de batería y accesibilidad para el usuario.

Formatos de vídeo

MP4 (H.264 + AAC) Universal

Máxima compatibilidad en todos los navegadores de escritorio y móviles. Formato principal imprescindible.

WebM (VP9 / AV1) Alta compresión

Código abierto y menor tasa de bits manteniendo calidad. Ideal como primera fuente alternativa antes de MP4.

Formatos de audio

MP3 (audio/mpeg) Estándar web

Soporte total en cualquier navegador y dispositivo. La opción más segura y estable.

Ogg / AAC / WAV Alternativas

Ogg Vorbis para entornos de código abierto, AAC para streaming de alta fidelidad y WAV para muestras sin compresión.

Decálogo de experiencia de usuario en multimedia (UX)

01
Autonomía en el sonido

Nunca reproduzcas audio de forma imprevista. El usuario debe decidir cuándo y cómo escuchar.

02
Economía de datos móviles

Emplea preload="none" o preload="metadata" para no consumir la cuota de conexión del usuario antes de que pulse reproducir.

03
Feedback y carátula clara

Un buen atributo poster contextualiza el vídeo y comunica qué contenido encontrará el usuario.

04
Inclusión para todos

Acompaña siempre tus vídeos con subtítulos <track> o proporciona una transcripción textual descargable.
