Repositorio de ejemplos de código para el módulo de **Diseño de interfaces web (DIW)**, de segundo curso de Desarrollo de aplicaciones web.

Cada ejemplo relaciona el código fuente con su representación visual para apoyar las presentaciones teóricas y facilitar su consulta desde GitHub Pages.

## Contenido

- [Portada](index.html): índice visual de las micro-lecciones.
- [UT1](UT1/index.html): unidad agrupada sobre fundamentos del diseño visual e interacción, incluyendo elementos visuales, distribución, tipografía web e iconografía.
- [Documento de diseño](DESIGN-DOCUMENT.md): objetivos, arquitectura, sistema visual, accesibilidad y decisiones de implementación de la web.

## Cómo consultar los ejemplos

Abre cualquiera de los archivos `.html` en el navegador. Cada documento incluye su hoja de estilos `.css` asociada y funciona como una página estática, sin instalación ni proceso de compilación.

## Para el alumnado

Los ejemplos están pensados para leer, modificar y comparar el HTML y el CSS con el resultado visual. Las nuevas propuestas deben incorporarse en la unidad que corresponda, conservar rutas relativas y mantener una estructura accesible y fácil de seguir.

## Publicación

El repositorio está preparado para publicarse como sitio estático mediante [GitHub Pages](https://pages.github.com/). La configuración concreta de la rama y la carpeta de publicación se define en los ajustes del repositorio.
