Control con HTMLMediaElement

Ocultando los controles nativos del navegador, JavaScript nos permite construir reproductores personalizados con identidad de marca y control preciso sobre el estado, volumen y barra de tiempo.

Demostración en vivo API JS Nativa

Reproductor personalizado por JavaScript

Este reproductor no utiliza el atributo controls. Toda la interacción (play, pausa, mute, avance y volumen) se gestiona mediante métodos y propiedades de HTMLMediaElement.

Lógica JavaScript 
// Métodos y propiedades clave de HTMLMediaElement
const media = document.querySelector('#miAudio');

// Reproducción y pausa programática
media.play();  // Devuelve una Promise
media.pause(); // Pausa inmediata

// Sincronización en tiempo real
media.addEventListener('timeupdate', () => {
  const progreso = (media.currentTime / media.duration) * 100;
  seekBar.value = progreso;
});
Referencia técnica CE 4.E · CE 4.F

Métodos, propiedades y eventos esenciales

  • .play() Inicia la reproducción. Devuelve una Promesa susceptible de ser rechazada por políticas de autoplay.
  • .pause() Detiene la reproducción sin reiniciar la posición temporal.
  • .currentTime Lectura y escritura del punto actual de reproducción en segundos. Permite saltos temporales.
  • .duration Longitud total en segundos. Disponible tras el evento loadedmetadata.
  • .volume Nivel de audio en escala flotante de 0.0 (silencio) a 1.0 (máximo).
  • timeupdate Evento emitido recurrentemente conforme avanza el cabezal de lectura.

SVG dinámico en el DOM

Al insertar gráficos vectoriales SVG de forma inline, sus formas forman parte del árbol DOM y pueden inspeccionarse, animarse y reaccionar a eventos igual que un botón o un párrafo HTML.

Gráfico reactivo SVG Inline + DOM API

Manipulación vectorial en tiempo real

Interactúa con los controles o pulsa directamente sobre el nodo circular del SVG para comprobar la reactividad del DOM.

Estado DOM: fill: #eab84b
Manipulación de SVG con JS 
// Selección directa del nodo SVG en el árbol DOM
const circulo = document.querySelector('#svg-dynamic-circle');

// Modificar atributos de presentación
circulo.setAttribute('fill', '#ef745f');

// Animar trazo con stroke-dashoffset
const arco = document.querySelector('#svg-progress-arc');
arco.style.strokeDashoffset = '141px'; // 50% de la circunferencia
Ventajas de diseño SVG vs Raster

¿Por qué SVG inline en interfaces?

  • Escalabilidad Nitidez matemática infinita en pantallas Retina sin aumentar el peso de transferencia en kilobytes.
  • Estilos con CSS Soporta pseudoclases :hover, variables CSS (currentColor) y transiciones fluidas.
  • Accesibilidad Se etiqueta semánticamente con role="img", <title> y aria-label.
  • Animación de trazos La técnica de stroke-dasharray y stroke-dashoffset permite crear loaders y diagramas dinámicos.

Bloque 03

Bucles: requestAnimationFrame

Para animaciones complejas y renderizado gráfico sobre <canvas>, requestAnimationFrame sincroniza los cálculos con el refresco de pantalla (60 Hz) optimizando la batería y el rendimiento.

Lienzo en tiempo real Canvas 2D + rAF

Osciloscopio armónico a 60 fps

El bucle recalcula las funciones trigonométricas y dibuja el trazado en cada cuadro. Prueba a pausar o ajustar la frecuencia.

60 FPS
Patrón del bucle de animación 
function animar(timestamp) {
  // 1. Limpiar el lienzo
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // 2. Calcular nuevo estado y dibujar
  dibujarOnda(fase);
  fase += velocidad;

  // 3. Solicitar el siguiente fotograma al navegador
  requestAnimationFrame(animar);
}
requestAnimationFrame(animar);
Comparativa técnica rAF vs setInterval

requestAnimationFrame frente a temporizadores clásicos

  • Sincronización v-sync rAF se ejecuta justo antes del repintado de la pantalla, evitando tearing o saltos de fotogramas (jank).
  • Ahorro de batería Se detiene automáticamente cuando la pestaña está en segundo plano. setInterval sigue consumiendo CPU.
  • prefers-reduced-motion Permite consultar matchMedia() para pausar o reducir drásticamente los cálculos ante mareos visuales.

// Instanciación por JavaScript
const modalEl = document.querySelector('#demoModal');
const modal = new bootstrap.Modal(modalEl);

modal.show();

Accesibilidad WCAG 2.2 · ARIA

Buenas prácticas en modales interactivos

  • Atrapado de foco (Focus Trap) La tecla Tab no debe escapar del diálogo mientras el modal esté abierto. Bootstrap lo gestiona automáticamente.
  • Cierre con Escape El usuario debe poder cerrar el diálogo pulsando Esc en cualquier momento.
  • Restauración de foco Al cerrarse, el foco del teclado debe regresar al botón disparador que lo abrió.
  • Atributos semánticos Requiere role="dialog", aria-modal="true" y aria-labelledby apuntando al título.

Componente Modal Interactivo

Accesibilidad activa: El foco se encuentra atrapado dentro del cuadro de diálogo. Pulsa Esc o el botón de cierre para retornar el foco al botón de origen.
