Ejemplo sencillo con mixins y funciones

Una página minimalista para ver cómo SCSS nos ayuda a reutilizar estilos y a generar valores de forma más clara y mantenible.

Mixin

Tarjeta base

El mixin reutiliza la misma forma para crear cajas con sombra, radio y espaciado homogéneo.

Función

Espaciado

La función spacing() calcula tamaños de separación con Sass y evita repetir valores mágicos.

Native

Color

lighten(), darken() y adjust-color() permiten variar tonos sin crear manualmente nuevas paletas.

Qué estamos usando

  • @mixin para reutilizar estilos de botones y tarjetas.
  • @function para calcular espacios con sass:math.
  • lighten(), darken() y adjust-color() como funciones nativas.
