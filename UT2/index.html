Unidad de trabajo 02 · Uso de estilos

Tres formas
de aplicar CSS.

CSS puede aplicarse a los documentos HTML de tres formas distintas, cada una con sus ventajas y casos de uso específicos.

01 Tipos de aplicación de estilos CSS 02 Conmutación dinámica de temas

Bloque 01

Tipos de aplicación de estilos CSS

El lugar donde se define una regla determina su prioridad, su alcance y lo fácil que será reutilizarla y mantenerla.

01 · Estilos en línea

Texto con estilo directo

Se declara en la propia etiqueta mediante `style`. Tiene máxima prioridad, pero dificulta la reutilización y el mantenimiento.

<p style="color:red;">Texto</p>
02 · Estilos internos

Texto con una regla en <style>

Se define dentro de una etiqueta `<style>` en el `<head>`. Es útil para una página única, pero no se reutiliza entre documentos.

<style> p { color: blue; } </style>
03 · Hojas externas

Texto con una hoja CSS vinculada

Es un archivo `.css` independiente asociado desde el `<head>`. Es la opción recomendada por su reutilización y mantenibilidad.

<link rel="stylesheet" href="css/estilos.css">

El tema también puede cambiar.

JavaScript puede activar hojas alternativas en tiempo de ejecución. Así, la persona elige su preferencia sin recargar la página ni alterar el HTML.
