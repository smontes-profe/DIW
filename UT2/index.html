Bloque 01

La cascada decide.

Los estilos pueden vivir en una etiqueta, en una clase o en una hoja externa. La forma de asociarlos cambia su alcance y su mantenimiento.

Inline · directo

Este párrafo recibe un estilo directamente.

style="color: coral"
Clase · reutilizable

Esta regla puede aplicarse a varios elementos.

.accent-text { color: coral; }
Hoja externa · global

Una hoja asociada mantiene el sistema en un solo lugar.

<link rel="stylesheet" href="index.css">

Bloque 03

Pensar en sistemas.

Los preprocesadores permiten trabajar con variables, mixins y funciones, y traducir después ese lenguaje a CSS estándar para el navegador.

SCSS · fuente
$accent: #e86d59;

@mixin card-border($color) {
  border-top: 4px solid $color;
}

.card {
  @include card-border($accent);
}
→
CSS · resultado
.card {
  border-top: 4px solid #e86d59;
}
