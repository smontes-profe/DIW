Unidad de trabajo 02 · Uso de estilos

Tres formas
de aplicar CSS.

CSS puede aplicarse a los documentos HTML de tres formas distintas, cada una con sus ventajas y casos de uso específicos.

Bloque 01

Tipos de aplicación de estilos CSS

El lugar donde se define una regla determina su prioridad, su alcance y lo fácil que será reutilizarla y mantenerla.

01 · Estilos en línea

Texto con estilo directo

Se declara en la propia etiqueta mediante `style`. Tiene máxima prioridad, pero dificulta la reutilización y el mantenimiento.

<p style="color:red;">Texto</p>
02 · Estilos internos

Texto con una regla en <style>

Se define dentro de una etiqueta `<style>` en el `<head>`. Es útil para una página única, pero no se reutiliza entre documentos.

<style> p { color: blue; } </style>
03 · Hojas externas

Texto con una hoja CSS vinculada

Es un archivo `.css` independiente asociado desde el `<head>`. Es la opción recomendada por su reutilización y mantenibilidad.

<link rel="stylesheet" href="css/estilos.css">

Bloque 03

Seleccionar para dar forma.

Un selector indica qué elementos HTML recibirán una regla CSS. Su alcance puede ser global, por tipo, reutilizable, único o contextual.

*

Universal

Aplica la regla a todos los elementos del documento.

divpa 
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
p

Tipo / etiqueta

Selecciona todas las etiquetas del mismo tipo.

<p>Texto</p>

<p>Otro texto</p>

p {
  color: #39759b;
}
.

Clase

Es reutilizable en múltiples elementos mediante `class`.

class="destacado"class="destacado" 
.destacado {
  color: #e86d59;
  font-weight: 700;
}
#

Identificador

Es único por página y tiene más especificidad que una clase.

id="selector-example-id" 
#selector-example-id {
  border-left: 4px solid #1d9c91;
}
›

Contextual

Selecciona por jerarquía dentro del árbol DOM.

  • ul li a
.contenedor .tarjeta 
ul li a {
  text-decoration: none;
}
.contenedor .tarjeta {
  padding: 1rem;
}

Bloque 04

Cada caja tiene capas.

El modelo de caja explica cómo se calcula el espacio que ocupa un elemento: contenido, relleno, borde y margen. Inspecciona la demo con las herramientas de desarrollo de Chrome y cambia sus valores.

margin: 28px
border: 8px
padding: 24px
content 120 × 70 px
ContentEl contenido: texto, imagen o componente.
PaddingEspacio interno entre contenido y borde.
BorderLímite visible de la caja.
MarginEspacio externo que separa otras cajas.
HTML 
<article class="caja">
  <h3>content</h3>
</article>
CSS 
.caja {
  width: 120px;
  height: 70px;
  padding: 24px;
  border: 8px solid teal;
  margin: 28px;
}
